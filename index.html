SOBRE MÍ

Backend, automatización y lógica de negocio

Desarrollo software pensado para organizar información, conectar sistemas y convertir procesos manuales en herramientas digitales funcionales.

01
INTRODUCCIÓN Y RECORRIDO

Con más de 3 años de formación y experiencia práctica en el desarrollo backend, he orientado mi recorrido hacia la creación de aplicaciones que gestionan procesos internos y resuelven necesidades reales dentro de empresas y organizaciones.

Mi trabajo se centra en recibir datos desde múltiples fuentes, procesarlos, aplicar reglas de negocio y convertirlos en acciones, registros o resultados que puedan utilizarse dentro de un flujo de trabajo.

02 TECNOLOGÍAS QUE UTILIZO

Utilizo Java y Spring Boot para desarrollar aplicaciones backend, servicios y APIs REST que concentran la lógica principal de cada sistema.

Cuando el proyecto requiere automatizar tareas, procesar documentos o transformar información, trabajo con Python y librerías adaptadas al formato de los datos.

Java Spring Boot Python REST APIs MySQL PostgreSQL Git Docker
03 METODOLOGÍA Y ARQUITECTURA

Organizo los proyectos mediante una arquitectura por capas, separando la entrada de datos, la lógica de negocio, el acceso a la información y la comunicación con servicios externos.

Durante el desarrollo trabajo de forma incremental: analizo el proceso, divido el problema en responsabilidades, implemento cada flujo y compruebo su funcionamiento antes de integrar la siguiente parte.

01 Entrada APIs, archivos o formularios
02 Procesamiento Validación y transformación
03 Negocio Reglas y decisiones
04 Resultado Datos, archivos o acciones

Gestión de datos

Validación, transformación y almacenamiento de información procedente de distintos sistemas y formatos.

Integración de servicios

Desarrollo y consumo de APIs para comunicar aplicaciones, plataformas externas y herramientas internas.

Software empresarial

Herramientas adaptadas a procesos reales, desde la gestión de licencias hasta la coordinación automática de operaciones.
