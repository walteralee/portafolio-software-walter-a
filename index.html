SOBRE MÍ

Backend, automatización y lógica de negocio

Desarrollo aplicaciones backend estructuradas en capas, trabajando con lógica de negocio, gestión y persistencia de datos, APIs e integración con servicios externos.

01
INTRODUCCIÓN Y RECORRIDO

Con más de 3 años de formación y experiencia práctica en el desarrollo backend, he orientado mi recorrido hacia la creación de aplicaciones centradas en la gestión de datos, la organización de procesos y la integración entre distintas partes de un sistema.

Mi trabajo se centra en recibir datos desde múltiples fuentes, procesarlos, aplicar reglas de negocio y convertirlos en acciones, registros o resultados que puedan utilizarse dentro de un flujo de trabajo.

02 TECNOLOGÍAS QUE UTILIZO

Mi lenguaje principal es Java, que utilizo junto con Spring Boot para desarrollar aplicaciones backend, servicios y APIs REST. Trabajo con Hibernate como ORM para gestionar la persistencia y el acceso a datos dentro de las aplicaciones.

En bases de datos trabajo principalmente con MySQL dentro del ecosistema SQL y con MongoDB cuando el proyecto requiere un enfoque NoSQL. También estoy familiarizado con el consumo, diseño y documentación de APIs, utilizando principalmente Postman.

Utilizo Python como lenguaje complementario para automatizaciones, procesamiento de datos, scripts y otras tareas que requieren una solución más flexible. También integro herramientas y servicios de inteligencia artificial dentro del desarrollo cuando pueden aportar valor al flujo de trabajo o a la propia aplicación.

Para el desarrollo de interfaces trabajo con React, principalmente en aplicaciones web que necesitan complementar el backend con una interfaz gráfica.

En el control de versiones utilizo Git y GitHub, y para testing en Java trabajo con JUnit. Actualmente también estoy ampliando mis conocimientos en servicios cloud, especialmente dentro de Amazon Web Services (AWS).

03 METODOLOGÍA Y ARQUITECTURA

Organizo los proyectos mediante una arquitectura por capas, separando la entrada de datos, la lógica de negocio, el acceso a la información y la comunicación con servicios externos.

Antes de desarrollar, analizo el proceso que debe automatizarse o gestionarse y divido el sistema en responsabilidades. Organizo el flujo separando la entrada de datos —procedente de APIs, archivos o formularios—, su validación y transformación, la aplicación de las reglas de negocio y, por último, la generación del resultado en forma de datos, archivos o acciones.

Durante el desarrollo trabajo de forma incremental: implemento cada parte del flujo, compruebo su funcionamiento de forma aislada y la integro con el resto del sistema antes de continuar con la siguiente responsabilidad.

04 CASOS DE TRABAJO

En mis prácticas en Novacenter del Sur trabajé en la gestión y el mantenimiento de bases de datos y en la resolución de incidencias de software empresarial. Mi responsabilidad incluyó desarrollar una herramienta en Java para automatizar procesos internos, integrándola con una base de datos MySQL para mejorar la eficiencia en la gestión de licencias.

Como proyecto personal, diseñé y desarrollé la web corporativa de Flor de Tuna, un restaurante. Organicé el sitio en una estructura multipágina de carta, reservas, galería y contacto, apliqué HTML semántico orientado a SEO técnico y optimicé la carga y el rendimiento siguiendo métricas como las Core Web Vitals, dejando el proyecto preparado como base reutilizable para futuros clientes.

EN LA ACTUALIDAD

Continúo desarrollando proyectos donde el backend no es únicamente una API, sino el motor que organiza y automatiza todo el proceso.

Mi objetivo es seguir construyendo software que conecte datos, reglas de negocio y operaciones reales para reducir trabajo manual y mejorar la forma en la que se gestiona la información.

ABOUT ME

Backend, automation and business logic

I develop layered backend applications, working with business logic, data management and persistence, APIs, and integration with external services.

01
BACKGROUND AND EXPERIENCE

With more than 3 years of training and hands-on experience in backend development, I have focused my path on building applications centered on data management, process organization, and integration between different parts of a system.

My work focuses on receiving data from multiple sources, processing it, applying business rules and converting it into actions, records or results that can be used within a workflow.

02 TECHNOLOGIES I USE

My main programming language is Java, which I use together with Spring Boot to develop backend applications, services, and REST APIs. I work with Hibernate as an ORM to manage data persistence and access within applications.

For databases, I mainly work with MySQL within the SQL ecosystem and with MongoDB when a project requires a NoSQL approach. I am also familiar with API consumption, design, and documentation, mainly using Postman.

I use Python as a complementary language for automation, data processing, scripts, and other tasks that require a more flexible solution. I also integrate artificial intelligence tools and services into development when they can add value to the workflow or the application itself.

For interface development, I work with React, mainly in web applications that need to complement the backend with a graphical interface.

For version control, I use Git and GitHub, and for testing in Java I work with JUnit. I am currently also expanding my knowledge of cloud services, especially within Amazon Web Services (AWS).

03 METHODOLOGY AND ARCHITECTURE

I organize projects using a layered architecture, separating data input, business logic, data access and communication with external services.

Before developing, I analyze the process that needs to be automated or managed and divide the system into responsibilities. I organize the flow by separating data input —from APIs, files or forms—, its validation and transformation, the application of business rules and, finally, the generation of the result as data, files or actions.

I follow an incremental development process: I implement each part of the flow, verify its behavior in isolation and integrate it with the rest of the system before moving on to the next responsibility.

04 WORKING EXAMPLES

During my internship at Novacenter del Sur, I worked on database management and maintenance and on resolving business software issues. My responsibility included developing a Java tool to automate internal processes, integrating it with a MySQL database to improve the efficiency of license management.

As a personal project, I designed and built the corporate website for Flor de Tuna, a restaurant. I organized the site into a multi-page structure covering the menu, reservations, gallery and contact, applied semantic HTML focused on technical SEO, and optimized loading and performance following metrics such as Core Web Vitals, leaving the project ready as a reusable base for future clients.

CURRENTLY

I continue developing projects where the backend is not simply an API, but the engine that organizes and automates the entire process.

My goal is to continue building software that connects data, business rules and real operations to reduce manual work and improve how information is managed.
